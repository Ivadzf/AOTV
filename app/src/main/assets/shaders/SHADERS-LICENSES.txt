Shaders GLSL do painel "Melhorar imagem" (Lote mpv 2, v1.37.0)
===============================================================

Estes arquivos vao empacotados no APK (app/src/main/assets/shaders/) e sao
copiados p/ filesDir/mpv-shaders na primeira utilizacao; o mpv os recebe por
caminho absoluto via a opcao glsl-shaders. So arquivos desta lista entram
na allowlist do app (EnhanceCatalog.SHADER_ALLOWLIST) — nenhum caminho
arbitrario e aceito.

seguem o documento oficial do Anime4K (md/GLSL_Instructions_Advanced.md,
v4.x): A = Restore -> Upscale -> Upscale; B = Restore_Soft -> Upscale ->
Upscale; C = Upscale_Denoise -> Upscale; A+A = Restore -> Upscale ->
Restore -> Upscale; B+B = Restore_Soft -> Upscale -> Restore_Soft ->
Upscale; C+A = Upscale_Denoise -> Restore -> Upscale; sempre com
Clamp_Highlights no comeco e AutoDownscalePre_x2 entre as duas ampliacoes.
O mesmo arquivo nunca aparece 2x numa cadeia: os shaders Anime4K usam
//!SAVE com nomes fixos (ex.: conv2d_tf), e repetir o arquivo colide —
ver o aviso do proprio documento ("You can only use each shader file
once").
